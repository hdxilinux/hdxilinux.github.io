HDXI

HDXI, the High Definition Computing Environment, is a small independent Linux distribution built around a BSD-style ports system written in shell. It is highly experimental: the base is a single tarball you unpack onto a partition, and everything else is a port you build yourself.

It boots on UEFI machines, runs a Wayland desktop with dwl, foot and Firefox, and has working Wi-Fi on real hardware.

Download

The base tarball is published on the releases page of the GitHub repository. Installation media may come later; for now you install from any Linux live system by following the installation guide.

HDXI on GitHub – releases, installation guide, build scripts.

hdx

hdx is the port manager. It reads a port’s make.sh, checks the pinned checksum, builds from source and installs.

hdx i util-wpa_supplicant   # install a port
hdx r util-wpa_supplicant   # remove it
hdx l                       # list installed
hdx info devel-libnl        # show description

hdxp

The ports tree lives at /hdxp and is a plain git clone, so updating is git pull. Ports are sorted into four classes.

base
Kernel, bootloader and other parts the system needs to start.
util
Command-line tools.
devel
Libraries and build tools.
misc
Everything else, including firmware and desktop programs.

Technical specifications

Kernel
Mainline Linux 6.18 LTS, drivers built in, no initramfs.
Userland
musl libc and busybox.
Init
situation, a small shell init.
Bootloader
Limine, UEFI.
Desktop
dwl on wlroots, foot terminal, Firefox.
Packages
Source ports through hdx.
